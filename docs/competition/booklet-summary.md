# ModelX 2.0 – booklet summary
Source: https://modelx2.pages.dev/ (checked 15 Oct 2026). If anything here conflicts with the booklet, the booklet wins.

## Challenge
Build a system that gives people insight they couldn't reach alone: a pattern, risk, trend or anomaly. **Retrieval alone doesn't count.** Output must be trustworthy, show what the data can't support, and fail safely. Our domain: economy & livelihoods (template domain 01, cost of living and everyday economics).

## Submission 2
- Technical report: architecture, stack and why, honest evaluation against the proposal, data actually used (temporality and gaps)
- Public git repo with a README on how to run it (**private repo = no submission**)
- Two-page summary
- Three-minute video of the system working on real data

## Judging
**Implementation (cut to 15):** data work 30% · insight 25% · engineering 25% (structure, dependencies, sustained git history, report matches code) · demo 20%
**Final:** working live 35% · insight value 25% · problem significance 20% · depth under questioning 20%
**Best Data Vision award:** where the data came from, how it was obtained, whether it's current enough to act on.

## Rules
- Original work during the competition; pre-built system = disqualified.
- Open-source libraries, pretrained models and public data allowed, with credit.
- AI use allowed but must be disclosed (see docs/ai_use_log.md).
- Data must be licensed, ToS-covered or documented as permitted. Respect robots.txt. Minimise personal data.
- Deadlines are firm.
