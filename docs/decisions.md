| **D44** | 3 Nov: **Price anomaly check uses a per-stock yardstick, not a fixed %.** Remove the market's move that day (median of all stocks), compare each stock's leftover with its own normal size over the last 60 days (MAD), flag above 8x that size; plain 15% limit only where there is no history yet. | **D45** | 3 Nov: **Automatic handling of flagged prices, no manual checking.** Clear splits are adjusted; other flagged days stay in the data (real shocks). Average returns use a capped copy (each stock's 1st-99th percentile) so one wild day cannot drag them; risk and the simulation use the uncapped returns. Each stock gets a confidence label (high / medium / low from days of history and unexplained flags), a recent-odd-day warning, and a robust yes/no (average return moves by less than 5 points when extremes are capped). One command, `src/data/run_pipeline.py`, runs every step and stops if one fails; the daily GitHub Action runs it (still switched off). Everything is logged in data/clean/adjustments_log.csv and data_quality.csv | Judges want data handled and gaps shown; a human only reads the log |

| **D48** | 8 Nov: **Risk profile and a separate knowledge cap.** Based on the CFA Institute's "Investment Risk Profiling: A Guide for Financial Advisors" (rpc.cfainstitute.org), which treats risk tolerance/capacity and financial knowledge/experience as separate things, with knowledge setting a ceiling that a high risk score should not override. 4 behaviour-based quiz questions (loss reaction, time horizon, preference, emergency fund - no self-labels like "are you risk tolerant", no jargon like "aggressive") give a profile (Cautious to Adventurous) and a fixed % split.
