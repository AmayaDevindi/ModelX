How our Sri Lanka investment guide will work

Think LankaBizz-style market data in a Bloomberg-style multi-panel dashboard, plus the part nobody in Sri Lanka does yet: a personal plan. A person enters how much they have, takes a short risk quiz and picks a goal and time horizon. The tool shows how they could split that money across savings, FDs, treasuries, unit trusts and S&P SL20 shares, a forecast of where the portfolio could go, the chance of losing money, the monthly income, and how it compares with an FD after inflation. Built on public data that refreshes every weekday. Educational, not investment advice.

Four sites shaped the plan. None of them tells a beginner how to split their own money across FDs, treasuries, unit trusts and shares, and then shows what that split might do. That is the gap we fill.

Bloomberg Terminal

professional.bloomberg.com/products/bloomberg-terminal

The professional's tool: data, news, research, analytics and charts in one workspace. Built for traders and fund managers.

What we take

  • Multi-panel layout: many small panels on one screen (their Launchpad workspace)
  • Market monitors where each number has a time stamp
  • News next to the numbers it affects
  • Plain-English help for new users (their Terminal Essentials videos)

What we leave

  • The dark terminal look and keyboard commands
  • Trading, messaging, pro-only depth

Shows up as: the home dashboard layout and the "data as of" stamps.

LankaBizz

lankabizz.net

Sri Lankan business and market-data site: economy trackers, CSE data, unit trusts, news, AI stock picks, AI chat. Most of it needs a free sign-up.

What we take

  • Tracker pages: interest rates, inflation, FX, gold
  • Unit trust explorer
  • Stock screener (we limit it to S&P SL20)
  • Economy / sector outlook
  • Business news section

What we leave

  • AI stock picks and trading signals: we stay at the level of a whole plan, not "buy this share"
  • Open AI chat: we use preset questions instead

Shows up as: the rates monitor and the four extra pages.

Waraka.lk

waraka.lk

Sri Lanka's unit trust platform: compare, analyse and invest in 80+ funds from licensed fund managers.

What we take

  • The idea of a forecast on a portfolio, not just past returns
  • Comparing funds side by side
  • Possibly fund NAV data, only if their terms allow it

What we leave

  • Unit trusts only: we cover FDs, treasuries and shares too
  • Selling funds: we don't take money or place orders

Shows up as: the portfolio forecast panel. Later: entering a portfolio you already hold.

First Guardian Equities

fge.lk/market-insight

An SEC-licensed stockbroker and CSE trading participant. Posts weekly market updates (as images) and monthly market wrap-ups.

What we take

  • Format for our own weekly market wrap
  • Monthly wrap-ups cited as a source in the outlook page and proposal
  • Which news actually matters to investors
  • Their risk wording: "past performance doesn't guarantee future results"

What we leave

  • Using their weekly images as a data feed (images, and the latest weekly one we saw was from May)

Shows up as: the weekly wrap panel, cited sources, disclaimer wording.

Rule of thumb: we want 3+ years of daily or weekly history to train on. A source that only gives today's value can still feed the live site, but it needs a separate history source.

Everything runs on free services. There's no server to rent: GitHub runs the daily Python job and stores the data as JSON files, and Vercel hosts the Next.js website that reads them.

Why these choices

  • Python for data and models, React for the site: the team knows both, and a dashboard like Bloomberg's needs the layout control React gives.
  • GitHub Actions instead of an AI agent (D5): reliable, free, and every daily pull shows up in the git history the judges score.
  • JSON files in the repo instead of a database: the data is small (tens of MB), and git keeps every version for free.
  • Vercel: free hosting for Next.js that rebuilds the site whenever the daily job pushes new data.
  • No login yet: nothing personal is stored before 1 Nov; a saved-plans login is decided after.

Cost and limits

GitHub public repo: free Actions on public repos: free Vercel hobby plan: free FinBERT: open model LLM API: only with a student plan / free credits

Limits to plan around: Action schedules can run a few minutes late. Headlines are scored once inside the daily job, never live, so the site stays fast and the LLM bill stays at zero or close to it.

The final is scored partly on how the system handles what it doesn't know. These are the rules the tool follows, and each one is visible to the user.

Never promises profit

Every result is a range, with the chance of loss stated next to it (D2). We never show a single "you will earn" number.

Shows how fresh the data is

Every number carries a "data as of" date (D3). If a source misses a day, the site keeps the last good value and shows a stale-data warning.

Falls back to the baseline

ML forecasts are only used where they beat a simple historical average on unseen data (D4). Otherwise the tool uses the average and says the data is too weak to do better.

Checks itself against an FD

Every split is compared with keeping it all in an FD after inflation, so the user can see if the extra risk is worth it.

Says what it can't see

It doesn't cover personal tax situations, fees, liquidity needs or company-specific news. It says so on the result screen.

Preset questions, not a chatbot

"Why this split?" answers are written from the actual numbers behind the plan, so the tool can't make things up the way a free-text AI chat can.

News is context, not a signal

The sentiment score is shown next to headlines. It only enters a forecast if it beats the baseline in testing, like any other input.

Educational, not advice

There are no buy or sell instructions on named shares, and there is a clear disclaimer. Wording to be checked with the stockbroker and against SEC Sri Lanka rules.
